Suggest the correct spelling

Type the word exactly as you want it written, for example “quinoa”. Use normal spelling, not a pronunciation or phonetic spelling. This is an optional hint for browsers that support it, not an automatic correction. If the same wrong text keeps appearing, use “Replace misrecognized text” below.

    Replace misrecognized text

    Copy the incorrect text from your dictation into the first field. Enter the correct text in the second. For example: if the app writes “keen wah”, replace it with “quinoa”. Enter what actually appeared, not how you pronounce the word. The replacement applies to future dictation in every supported browser.
